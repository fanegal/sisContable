# sisContable

Sistema contable con API backend, frontend web y procesos automatizados.

## Structure
- `backend` — API en PHP (Controllers, Models, Middlewares, Routes)
- `web` — frontend web
- `robot` — procesos automatizados

## Stack
PHP >= 7.4 · Composer

## How to run the API
1. `composer install` inside `backend`.
2. `php -S localhost:8000 -t public`
3. Open http://localhost:8000

See `backend/README.md` for full backend instructions.
